## ⭐ Recommended Default Stack

For most small projects, we can start with:

```text
GitHub
   ↓
GitHub Actions
   ↓
┌───────────────────────────────┐
│ Frontend → Vercel             │
│ Backend  → Render / Koyeb     │
│ Database → Supabase / Neon    │
│ Redis    → Upstash            │
│ Storage  → Cloudflare R2      │
└───────────────────────────────┘
   ↓
Cloudflare
   ↓
DNS + CDN + SSL + Security
```

### Development

* **GitHub** → Source control
* **GitHub Actions** → CI/CD
* **Postman** → API testing
* **Swagger** → API documentation
* **Cloudflare Tunnel** → Local webhook testing

### Production

* **Vercel / Cloudflare Pages** → Frontend
* **Render / Koyeb** → Backend
* **Supabase / Neon** → PostgreSQL
* **MongoDB Atlas** → MongoDB
* **Upstash** → Redis
* **Cloudflare R2** → Files
* **Sentry** → Errors
* **UptimeRobot** → Uptime
* **PostHog** → Analytics

> Free tiers change frequently. This README is a quick developer reference, not a guarantee of current limits or availability.
